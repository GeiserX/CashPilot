Coming from money4band, CashFactory or InternetIncome? Add the config files from that tool and CashPilot shows what it can bring over before it saves anything. Nothing in the files is run or fetched, and the files themselves are not kept.

1. Your old config

money4band: config/user-config.json (or its .env). CashFactory: .env. InternetIncome: properties.conf, plus earnapp.txt and proxyrack.txt if you have them, so your linked devices come over. Up to 4 files, 64 KiB in total. The guides under "Moving from another tool" in the docs explain each tool.

3. Deploy what you imported

Saved imports stay here, encrypted, so you can deploy them to more workers later. Stop the old tool on a machine before you deploy there: two copies behind one connection earn as one, and a device id must not run twice.
