M1 · Proxies & VPNs page and the Add egress wizard

Each earning service pays once per public IP. Today, extra IPs (proxies, a second site over Tailscale) live at the bottom of Fleet, owner-only, one 9-field form per proxy, no VPN option, and a green Test only proves a TCP connection. This plan gives them their own page, a paste-many dialog, a test that checks each vendor through the proxy, and a CLI line for every action.

Mockup, dark theme, data fake (IPs from 203.0.113.0/24, ASN 64500). Colours, type and components are copied from app/static/css/style.css on origin/main. Purple numbered circles are notes for the reader, not part of the UI.

BEFORE Adding ten proxies today

Fleet → scroll → “Add a proxy”

  • Lives inside Fleet below the boxes, owner-only (fleet.html:76-80). Not in the nav, not in the setup wizard.
  • One proxy = Name, Type, Host, Port, User, Password, Cap, Stop %, Reset day, Rotating, Save (fleet.html:92-110). A provider sends a list of 10: ≈ 80 inputs plus 10 Saves.
  • Types: SOCKS5, HTTP, Tailscale exit (fleet.html:93-96). No WireGuard or OpenVPN file, no provider picker.
  • Test checks the tunnel and exit IP only (tunnel/cp-probe:8-14): a proxy that 403s PacketStream still shows green, and the copy earns nothing.
  • Running a copy is a second form with three selects, one copy per submit (fleet.html:114-123).
  • Keyboard: no shortcut reaches it; Tab from the top of Fleet takes 30+ presses (screenshot walkthrough/shots/36-kbd-fleet-proxy.png).

CLI · API Same actions without the browser
