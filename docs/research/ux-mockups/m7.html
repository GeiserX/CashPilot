Use from a terminal

The cashpilot CLI talks to this dashboard over the same API. Every command takes --json, --dry-run on anything that changes a box, and exits non-zero on refusal.

Install, on any machine
$ uvx cashpilot --versionCopy
Or, with no install, inside the dashboard container
$ docker exec cashpilot-ui cashpilot statusCopy
Sign in once (the token is read from stdin, never from argv or history)
$ cashpilot login --url http://cashpilot.local:8080 --token-stdinCopy

The URL above is this dashboard's own address, filled in for you. CLI reference

Stateful services: plan, then confirm

Storj, Mysterium and other nodes with an identity volume never lose data by default. Every remove, stop or redeploy returns a plan first:

# 1. read the plan cashpilot service rm mysterium --box box-a --dry-run --json # 2. remove, keeping the identity volume cashpilot service rm mysterium --box box-a --yes # 3. only if the owner asked: delete the volume too cashpilot service rm mysterium --box box-a --yes --delete-volume=mysterium

The volume flag must repeat the slug, the same check as the dialog in M8. Over HTTP, add dry_run=1 to the same request: it returns {"plan": …, "plan_id": "…"}; send plan_id back within 5 minutes.
