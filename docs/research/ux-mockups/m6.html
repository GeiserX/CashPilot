A setup wizard you can finish with the keyboard, on one box, without a toast to chase

Four problems in the wizard on origin/main. (1) Service cards in step 2 are <div data-action="toggleWizardService"> with no tabindex or role (app.js:3078), so Tab skips them: a keyboard user cannot pick a service at all. (2) Each service's "Deploy to" box starts unticked even when only one box exists (app.js:1798-1800); pressing Deploy only says "Select at least one worker node" in a toast (app.js:3325-3329). The summary then blames a missing online worker (app.js:2959-2961), which was not the cause. (3) Credentials that already run the service have to be typed again under Settings → Collectors to see a balance (app.js:3163-3170). (4) The preflight warning is a native window.confirm (app.js:3319-3321), and results and "kept settings" notes are toasts that disappear (app.js:3395-3401).
