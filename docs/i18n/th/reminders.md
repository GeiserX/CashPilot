# เงินที่รออยู่: การเตือนก่อนเสียรายได้ { #money-waiting-reminders-before-you-lose-earnings }

ผู้ให้บริการบางรายจะริบเงินที่ค้างอยู่นานเกินไป ยอดคงเหลืออาจหมดอายุหลังจาก
ไม่มีกิจกรรมหลายเดือน ช่วงเวลาเคลมอาจปิดลง ผู้ให้บริการอาจแบนบัญชี หยุดจ่ายเงิน
หรือปิดกิจการในขณะที่ยอดคงเหลือยังอยู่
CashPilot อ่านข้อมูลส่วนใหญ่ที่ต้องใช้เพื่อมองเห็นเหตุการณ์เหล่านี้ล่วงหน้าอยู่แล้ว
แผง **Money waiting** (เงินที่รออยู่) บนแดชบอร์ดแสดงสิ่งที่ต้องทำและกำหนดเวลา
และช่องทางการแจ้งเตือนจะได้รับข้อความพุชก่อนถึงแต่ละกำหนด

CashPilot ไม่เคยเคลมหรือถอนเงินแทนผู้ใช้ การเตือนแต่ละรายการลิงก์ไปยัง
หน้าของผู้ให้บริการเอง และผู้ใช้ดำเนินการที่นั่น

## สิ่งที่ระบบเตือน { #what-it-reminds-you-about }

**กฎจากข้อกำหนดของผู้ให้บริการเอง** กฎแต่ละข้ออ้างอิงข้อกำหนดหรือหน้าช่วยเหลือของผู้ให้บริการ
และวันที่มีคนอ่านครั้งล่าสุด ลิงก์ **Source** (แหล่งที่มา) ในเมนู **More** (เพิ่มเติม) ของ
แถวนั้นจะเปิดหน้าดังกล่าว

| บริการ | การเตือน | เมื่อใด |
|---|---|---|
| Grass | เคลม USDC ของ Stage 2 | ภายใน 22 ม.ค. 2027 Grass จะเก็บส่วนที่ไม่ได้เคลมไว้ |
| MystNodes | เคลมรางวัลของเดือนที่แล้ว | ภายใน 30 วันหลังการแจกจ่ายรายเดือนแต่ละครั้ง |
| Honeygain | ถอนยอดคงเหลือ | 24 เดือนหลังจากยอดถึง $20 เป็นครั้งแรก |
| Honeygain | ให้อุปกรณ์แบ่งปันต่อไป หรือทำการจ่ายเงิน | 6 เดือนหลังกิจกรรมหรือการจ่ายเงินครั้งล่าสุด |
| Repocket | ให้อุปกรณ์แบ่งปันต่อไป หรือถอนเงิน | 12 เดือนหลังกิจกรรมหรือการจ่ายเงินครั้งล่าสุด |
| Bitping | ถอนยอดคงเหลือ | 12 เดือนหลังการถอนครั้งล่าสุด |
| Salad | หา Reward Points เพิ่ม หรือใช้ยอดคงเหลือ | 12 เดือนหลังจากยอดคงเหลือเพิ่มขึ้นครั้งล่าสุด การใช้ยอดบางส่วนไม่ได้รีเซ็ตเวลานี้ |

**การถอนเงิน** CashPilot แจ้งเมื่อยอดคงเหลือถึงยอดจ่ายขั้นต่ำของผู้ให้บริการ
ใช้กับทุกบริการที่ CashPilot เก็บข้อมูล ยกเว้นบริการที่
จ่ายเงินให้เอง ยอดคงเหลือต้องมีมูลค่าอย่างน้อย $5 ด้วย ผู้ให้บริการ
ที่มียอดขั้นต่ำ 5 เซนต์จึงไม่เตือนตั้งแต่เซนต์แรก เมื่อยอดขั้นต่ำของผู้ให้บริการ
สูงกว่า ระบบจะใช้ยอดขั้นต่ำของผู้ให้บริการ เมื่อ CashPilot แปลงค่า
ยอดขั้นต่ำหรือยอดคงเหลือไม่ได้ ก็จะไม่แสดงอะไร ระบบไม่เคยเดาว่า
ผู้ใช้ถอนเงินได้

**ข้อมูลรับรองหมดอายุ** ระบบส่งข้อความพุชก่อนที่โทเค็นหรือคุกกี้ที่บันทึกไว้จะหมดอายุ
CashPilot ใช้วันหมดอายุที่ระบุไว้ในข้อมูลรับรองนั้นเอง หากไม่ได้ระบุไว้
CashPilot จะใช้อายุการใช้งานตามปกติของข้อมูลรับรองประเภทนั้น นับ
จากวันที่บันทึก เจ้าของเห็นรายการนี้อยู่แล้วใต้ **Needs attention** (ต้องดำเนินการ)
พร้อมปุ่ม **Renew** (ต่ออายุ) แผงนี้จึงไม่แสดงซ้ำ มีเพียงเจ้าของที่ได้รับ
การเตือนเรื่องข้อมูลรับรองจาก API เช่นเดียวกับการตรวจสุขภาพข้อมูลรับรอง
ข้อมูลรับรองที่ผู้ให้บริการปฏิเสธจะอยู่ในกระดิ่งและถูกพุชไปแล้ว
จึงไม่ถูกพุชซ้ำ

## บริการที่ครอบคลุม { #which-services-it-covers }

การเตือนใช้กับบริการที่ใช้งานอยู่: บริการที่ติดตั้งใช้งานแล้ว บริการที่ตั้งค่า
เป็นภายนอกใน Settings หรือแอปที่โทรศัพท์รายงาน บริการที่ลบไปแล้ว
ยังนับอยู่ตราบที่ยังมียอดคงเหลือ เพราะนาฬิกานับการไม่มีกิจกรรมเริ่มเดิน
เมื่อบริการหยุด บริการแบบกำหนดเองและบริการที่ยุติแล้วไม่ได้รับการเตือน

## วันที่และ "or earlier" { #dates-and-or-earlier }

นาฬิกานับกิจกรรมนับจากสิ่งที่ CashPilot บันทึกไว้:

- ครั้งล่าสุดที่ยอดคงเหลือเพิ่มขึ้น
- การจ่ายเงินครั้งล่าสุด
- หรือค่าที่อ่านได้ครั้งแรกที่เท่ากับหรือสูงกว่ายอดขั้นต่ำ

บางครั้งนาฬิกาเริ่มเดินก่อนที่ CashPilot จะอ่านค่าครั้งแรก กำหนดเวลาจริง
จึงอาจเร็วกว่าที่ CashPilot มองเห็น และแถวนั้นจะแสดง
"by 3 Oct 2027 or earlier" (ภายใน 3 ต.ค. 2027 หรือเร็วกว่านั้น)

CashPilot ลบประวัติรายได้หลังจาก 400 วัน แต่นาฬิกาของ Honeygain
เดินนานถึง 730 วัน CashPilot จึงจัดเก็บจุดเริ่มต้นของนาฬิกาแต่ละตัวตั้งแต่ครั้งแรกที่
เห็น และเก็บไว้ต่อหลังจากประวัติที่อยู่เบื้องหลังหายไปแล้ว การจ่ายเงินจะรีเซ็ต
นาฬิกา ยกเว้นกรณีที่ผู้ให้บริการนับเฉพาะการหารายได้ Salad เป็นหนึ่งในนั้น:
การจ่ายเงินที่ยังเหลือยอดคงเหลือไม่ได้รีเซ็ตช่วง 12 เดือน

วันที่ตายตัวจะหายไปในวันถัดจากที่ผ่านไปแล้ว เพราะเงินหายไปแล้ว
นาฬิกาที่เลยกำหนดจะยังอยู่ และแจ้งว่าผู้ให้บริการอาจตัดเงิน
นั้นทิ้งไปแล้ว รายการนี้จะอยู่จนกว่าจะทำเครื่องหมายว่าเสร็จหรือปิดเสียง หรือจนกว่าการจ่ายเงิน
จะรีเซ็ต

## สิ่งที่ทำได้กับการเตือน { #what-you-can-do-with-a-reminder }

เจ้าของและผู้แก้ไขเห็นปุ่มต่าง ๆ ผู้ดูเห็นเฉพาะการเตือน มีเพียงเจ้าของ
ที่ดำเนินการกับการเตือนเรื่องข้อมูลรับรองได้

- **Done** (เสร็จแล้ว) หรือ **Requested** (ส่งคำขอแล้ว) สำหรับการถอนเงิน จะซ่อนการเตือนนี้ ช่วงเวลา
  รายเดือนจะกลับมาในเดือนถัดไป การถอนเงินจะกลับมาหนึ่งครั้งหลังจาก 14 วัน หาก
  ยอดคงเหลือยังอยู่ และถามว่าได้รับการจ่ายเงินแล้วหรือยัง ซึ่งยังอยู่
  ภายในช่วงเวลาโต้แย้ง 60 วันที่ผู้ให้บริการส่วนใหญ่ให้ไว้
- **Snooze** (เลื่อนไว้ก่อน) ซ่อนการเตือนไว้หนึ่งวันหรือหนึ่งสัปดาห์และระงับข้อความพุช การเลื่อนไม่เคย
  เลยคำเตือนสุดท้ายก่อนถึงกำหนด
- **Not for me** (ไม่เกี่ยวกับฉัน) ในเมนู **More** (เพิ่มเติม) ปิดเสียงการเตือนหนึ่งรายการ หรือทุกการเตือน
  ของบริการหนึ่ง ตัวอย่างหนึ่ง: Honeygain ในโหมด JumpTask ซึ่งยอดคงเหลือที่ไม่เปลี่ยน
  เป็นเรื่องปกติ การเตือนที่ปิดเสียงไว้จะแสดงที่ส่วนท้ายของแผง พร้อมปุ่ม
  **Unmute** (เปิดเสียง)

ทุกคนในบ้านใช้ตัวเลือกเหล่านี้ร่วมกัน เมื่อคนหนึ่งทำเครื่องหมายว่าการเตือนเสร็จแล้ว
ก็ถือว่าเสร็จสำหรับทุกคน แต่ละตัวเลือกบันทึกไว้ในบันทึกการตรวจสอบพร้อมชื่อของ
ผู้ที่เลือก

## ข้อความพุช { #pushes }

การเตือนส่งไปยังช่องทางที่ตั้งไว้สำหรับการแจ้งเตือน: ntfy, webhook หรือ Telegram
([การกำหนดค่า](configuration.md)) หากไม่ได้ตั้งช่องทางไว้ แผงนี้จะเป็น
ที่เดียวที่แสดงการเตือน

- หนึ่งข้อความพุชต่อหนึ่งคำเตือน ตัวอย่างเช่น Grass พุชก่อนถึงกำหนด 60, 30, 7 และ 1 วัน
  การเตือนที่เห็นครั้งแรกเมื่อเหลือ 5 วันก่อนกำหนดจะพุชครั้งเดียว โดยแจ้งว่าเหลือ 5
  วัน
- ข้อความพุชส่งเฉพาะระหว่าง 09:00 ถึง 21:00 CashPilot ใช้เขตเวลาของเจ้าของคนแรก
  จาก Settings แล้วจึงใช้ `TZ` ของคอนเทนเนอร์ แล้วจึงใช้ UTC คำเตือน
  ที่ถึงเวลาตอนกลางคืนจะส่งออกในการตรวจครั้งแรกหลัง 09:00
- เมื่อมีข้อความพุชที่ถึงกำหนดพร้อมกันมากกว่า 3 รายการ จะได้รับสรุปรายการเดียวแทน
  ซึ่งเกิดขึ้นในวันที่อัปเกรด เมื่อยอดคงเหลือทุกรายการที่เกินยอดขั้นต่ำปรากฏ
  พร้อมกัน
- ข้อความพุชระบุบริการ สิ่งที่ต้องทำ สิ่งที่จะเสียไป วันที่ และ
  ลิงก์ของผู้ให้บริการ ไม่เคยระบุยอดคงเหลือ ที่อยู่ id อุปกรณ์ หรือ
  ชื่อเวิร์กเกอร์ เพราะหัวข้อของ ntfy อาจเป็นสาธารณะได้
- เพย์โหลดของ webhook มี `kind: "obligation"` เพื่อให้ Home Assistant และเครื่องมือที่คล้ายกัน
  ส่งต่อได้ถูกที่

## สำหรับผู้ร่วมพัฒนาแคตตาล็อก { #for-catalog-contributors }

กฎอยู่ในไฟล์ YAML ของแต่ละบริการ ภายใต้ `obligations:`
`services/_schema.yml` อธิบายฟิลด์ต่าง ๆ ไว้ เพิ่มกฎเฉพาะเมื่อ
ข้อกำหนดหรือเอกสารของผู้ให้บริการเองระบุไว้ และเมื่อ CashPilot มองเห็นสัญญาณที่กฎนั้น
อาศัยได้ ลิงก์ของกฎต้องอยู่บนโดเมนของบริการนั้นเอง เพราะมีเว็บไซต์เคลมปลอม
ที่สร้างขึ้นสำหรับบริการเหล่านี้โดยเฉพาะ CI จะล้มเหลวเมื่อพบกฎที่ไม่ถูกต้อง และ
เมื่อพบกฎที่มีวันที่และเลยกำหนดมาแล้วเกิน 30 วัน
