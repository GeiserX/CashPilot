# ยอดการจ่ายเงินบนเชน { #on-chain-payout-balances }

เปิด **Payouts** (การจ่ายเงิน) เพื่อดูยอดคงเหลือที่ที่อยู่รับการจ่ายเงินสาธารณะ Bitcoin ใช้
[mempool.space](https://mempool.space/docs/api/rest) และ Kaspa ใช้
[api.kaspa.org](https://api.kaspa.org/docs) ส่วน Ethereum, Polygon และ Solana ใช้
โหนด RPC สาธารณะ CashPilot อ่านที่อยู่เหล่านี้ได้โดยไม่ต้องใช้คีย์

| สิ่งที่เห็น | ความหมาย |
|---|---|
| จำนวนเงิน | explorer รายงานยอดคงเหลือ ยอดที่รายงานเป็นศูนย์จะแสดงเป็นศูนย์ วางเมาส์เหนือจำนวนเงินเพื่อดูแหล่งที่มา |
| **Pending** (รอดำเนินการ) | บน Bitcoin นั้น explorer เห็นการเปลี่ยนแปลงที่ยังไม่ยืนยัน เครื่องหมายบวกหมายถึงมีเงินกำลังเข้า เครื่องหมายลบหมายถึงมีเงินกำลังถูกใช้ จำนวนที่ยืนยันแล้วแสดงแยกไว้ |
| **Could not check** (ตรวจสอบไม่ได้) | explorer ไม่ตอบสนอง หรือส่งข้อมูลที่ CashPilot อ่านไม่ได้ |
| **Address not valid** (ที่อยู่ไม่ถูกต้อง) | ที่อยู่ไม่ผ่านการตรวจสอบรูปแบบ CashPilot จึงข้ามคำขอนี้ |
| **Private chain** (เชนส่วนตัว) | การอ่านยอดคงเหลือ Monero ต้องใช้ private view key ของคุณ ให้ตรวจสอบยอดคงเหลือในกระเป๋าเงินเอง CashPilot ไม่เคยขอคีย์นี้ |
| ขีด | แถวนี้ไม่มีที่อยู่หรือตัวอ่าน หรือปิดการค้นหาไว้ เมื่อการตั้งค่าปิดการค้นหา ให้วางเมาส์เหนือขีดเพื่อดูว่าเป็นการตั้งค่าใด |

endpoint สาธารณะของ Kaspa รายงานยอดคงเหลือเพียงยอดเดียว ไม่มีจำนวนที่รอดำเนินการ
แยกต่างหาก

คอลัมน์บนเชนแสดงยอดคงเหลือที่ที่อยู่นั้นในขณะนี้ ซึ่งอาจรวม
การโอนจากแหล่งอื่นด้วย ยอดค้างจ่ายของพูลแสดงสิ่งที่พูล
ยังถือไว้ให้ การจ่ายเงินของ OCEAN ผ่าน Lightning ไม่ปรากฏในยอดคงเหลือ
บนเชน ยอดคงเหลือยังบอกไม่ได้ด้วยว่าการโอนใดมาจาก
พูลของคุณ

## เลือกปลายทางของการค้นหา { #choose-where-the-lookup-goes }

การค้นหาแต่ละครั้งเปิดเผยที่อยู่รับการจ่ายเงินสาธารณะและ IP ของเซิร์ฟเวอร์ UI ให้
explorer ทราบ explorer สามารถเชื่อมโยงที่อยู่ที่ตรวจสอบจาก IP เดียวกันได้

ตั้งค่า base URL ในสภาพแวดล้อมของคอนเทนเนอร์ UI หากรันโหนดของตัวเอง
ไม่ต้องตั้งตัวแปรหากต้องการใช้ค่าเริ่มต้น ตั้งเป็นค่าว่างเพื่อปิด
การค้นหาของเชนนั้น

ตัวอย่างเช่น ไฟล์ Compose override สำหรับบริการ UI อาจมีเนื้อหาดังนี้:

```yaml
services:
  cashpilot-ui:
    environment:
      CASHPILOT_ONCHAIN_URL_BITCOIN: "http://mempool.local:3006/api"
      CASHPILOT_ONCHAIN_URL_KASPA: ""
```

ใช้ base URL ของ Esplora หรือ Kaspa API เมื่อกำหนดค่า Bitcoin หรือ Kaspa
endpoint ของ Bitcoin ยังให้ค่าความยากของเครือข่ายและรางวัลบล็อกสำหรับ
[รายได้ที่คาดว่าจะได้รับ](fleet.md#running-costs) ของพูล Bitcoin ด้วย การอ่านนี้ต้องใช้
แบ็กเอนด์ mempool (API `/v1/mining` ของ mempool) เซิร์ฟเวอร์ Esplora ธรรมดาตอบได้เพียง
การค้นหายอดคงเหลือ และแถวของพูลจะไม่แสดงจำนวนที่คาดว่าจะได้รับ
สำหรับ Ethereum, Polygon และ Solana ให้ตั้งตัวแปรที่เกี่ยวข้อง
`CASHPILOT_ONCHAIN_URL_ETHEREUM`, `CASHPILOT_ONCHAIN_URL_POLYGON` หรือ
`CASHPILOT_ONCHAIN_URL_SOLANA` เป็น URL ของ RPC ของโหนด ใช้ URL แบบ HTTP หรือ HTTPS
ที่ไม่มีข้อมูลรับรอง query string หรือ fragment นำการเปลี่ยนแปลงไปใช้โดย
สร้างคอนเทนเนอร์ UI ใหม่ด้วยสภาพแวดล้อมใหม่
