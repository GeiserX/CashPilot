# أرصدة الدفع على السلسلة { #on-chain-payout-balances }

افتح **Payouts** (الدفعات) لترى الرصيد في عنوان دفع عام. يستخدم Bitcoin
[mempool.space](https://mempool.space/docs/api/rest) ويستخدم Kaspa
[api.kaspa.org](https://api.kaspa.org/docs). وتستخدم Ethereum وPolygon وSolana
عُقد RPC عامة. يستطيع CashPilot قراءة هذه العناوين بلا مفتاح.

| ما تراه | معناه |
|---|---|
| مبلغ | أبلغ المستكشف عن رصيد. والصفر المُبلَغ عنه يظهر صفرًا. مرّر المؤشر فوق المبلغ لترى المصدر. |
| **Pending** (معلّق) | على Bitcoin، يرى المستكشف تغييرًا غير مؤكَّد. علامة الزائد تعني أن أموالًا واردة. وعلامة الناقص تعني أن أموالًا تُنفق. ويُعرض المبلغ المؤكَّد منفصلًا. |
| **Could not check** (تعذّر الفحص) | لم يستجب المستكشف أو أرسل بيانات لم يستطع CashPilot قراءتها. |
| **Address not valid** (العنوان غير صالح) | فشل العنوان في فحص التنسيق. وتخطّى CashPilot الطلب. |
| **Private chain** (سلسلة خاصة) | قراءة رصيد Monero تحتاج إلى مفتاح العرض الخاص بك (private view key). تحقّق من الرصيد في محفظتك. لا يطلب منك CashPilot هذا المفتاح أبدًا. |
| شرطة | لا يوجد عنوان أو قارئ لهذا الصف، أو أن البحث معطّل. وعندما يعطّل إعدادٌ البحث، مرّر المؤشر فوق الشرطة لترى أي إعداد هو. |

تُبلغ نقطة النهاية العامة لـ Kaspa عن رصيد واحد. ولا تقدّم مبلغًا معلّقًا
منفصلًا.

يعرض عمود الرصيد على السلسلة الرصيد في العنوان في هذه اللحظة. وقد يتضمن
تحويلات من مصادر أخرى. أما الرصيد غير المدفوع في مجمّع التعدين فيعرض ما لا يزال المجمّع
يحتفظ به لك. ودفعة OCEAN عبر Lightning لا تظهر في
الرصيد على السلسلة. كما لا يستطيع الرصيد أن يخبرك بالتحويلات التي جاءت من
مجمّعك.

## اختر وجهة البحث { #choose-where-the-lookup-goes }

يشارك كل بحث عنوان الدفع العام الخاص بك وعنوان IP لخادم الواجهة مع
المستكشف. ويستطيع المستكشف أن يربط بين العناوين التي تفحصها من عنوان IP نفسه.

اضبط عنوان URL الأساسي في بيئة حاوية الواجهة إذا كنت تشغّل عقدتك الخاصة.
اترك المتغير غير مضبوط لاستخدام القيمة الافتراضية. واضبطه على قيمة فارغة لتعطيل
البحث لتلك السلسلة.

مثلًا، قد يحتوي ملف Compose override لخدمة الواجهة على:

```yaml
services:
  cashpilot-ui:
    environment:
      CASHPILOT_ONCHAIN_URL_BITCOIN: "http://mempool.local:3006/api"
      CASHPILOT_ONCHAIN_URL_KASPA: ""
```

استخدم عنوان URL الأساسي لواجهة Esplora أو Kaspa API عند ضبط Bitcoin أو Kaspa.
وتعطي نقطة النهاية الخاصة بـ Bitcoin أيضًا صعوبة الشبكة ومكافآت الكتل من أجل
[الأرباح المتوقعة](fleet.md#running-costs) لمجمّع Bitcoin. وتحتاج هذه القراءة إلى
واجهة mempool خلفية (واجهة `/v1/mining` API الخاصة بها)؛ أما خادم Esplora العادي فلا يجيب إلا عن
البحث عن الرصيد، وعندها لا يعرض صف المجمّع أي مبلغ متوقع.
بالنسبة إلى Ethereum وPolygon وSolana، اضبط المتغيرات المقابلة
`CASHPILOT_ONCHAIN_URL_ETHEREUM` أو `CASHPILOT_ONCHAIN_URL_POLYGON` أو
`CASHPILOT_ONCHAIN_URL_SOLANA` على عنوان URL لواجهة RPC الخاصة بعقدة. استخدم عنوان URL بصيغة HTTP أو HTTPS
بلا بيانات اعتماد، ولا سلسلة استعلام، ولا جزء (fragment). طبّق التغيير بإعادة
إنشاء حاوية الواجهة بالبيئة الجديدة.
