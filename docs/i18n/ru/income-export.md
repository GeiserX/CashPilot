# Экспорт доходов для налогов { #income-export-for-taxes }

Откройте **Payouts** (Выплаты), найдите **Income for taxes** (Доход для налогов) и выберите диапазон дат и валюту. **This year** (Этот год) охватывает период по сегодняшний день, а **Last year** (Прошлый год) — предыдущий календарный год. Оставьте даты пустыми, чтобы экспортировать доступную историю по сегодняшний день. CashPilot использует даты в UTC и включает оба конца диапазона.

CashPilot удаляет показания заработка через 400 дней после записи. CSV использует оставшуюся историю, поэтому прошлый год может содержать только часть заработанного или начисленного дохода.

## Выберите метод учёта { #choose-an-accounting-basis }

- **Кассовый метод.** Используйте строки выплат. Они фиксируют деньги, которые сервис выплатил. CashPilot включает только подтверждённые выплаты.
- **Метод начисления.** Используйте строки заработанного и начисленного. Строки заработанного показывают средства, которые вы можете вывести на условиях сервиса. Строки начисленного показывают невыплаченные средства в пуле, которые пул может так и не выплатить.

Для одного и того же дохода используйте один метод. Если добавить строки выплат к строкам заработанного и начисленного, одни и те же деньги могут быть посчитаны дважды. Проверьте, какой метод применяется в вашей декларации.

## Столбцы CSV { #csv-columns }

| Столбец | Значение |
|---|---|
| date | День в UTC более позднего показания или выплаты. Для выплаты используется дата, которую вы ввели, или день, когда CashPilot её обнаружил. |
| period_start | День в UTC предыдущего показания для этого сервиса и источника. Пусто для выплат. Промежуток между показаниями означает, что сумма охватывает весь интервал. |
| kind | earned, accrued или payout. |
| service | ID сервиса в CashPilot. |
| coin | Код валюты или токена, как его записал CashPilot. |
| amount | Сумма в этой валюте или токене. |
| usd_rate | Количество долларов США за единицу coin. |
| usd_value | Сумма в долларах США. |
| local_currency | Фиатная валюта, которую вы выбрали для экспорта. |
| local_rate | Единиц выбранной вами валюты за один доллар США. |
| local_value | Сумма в выбранной вами валюте. |
| method | Способ выплаты, если он записан. |

Пустая оценка означает, что курс был недоступен. Исходная сумма всё равно есть. CashPilot пропускает внутренние баллы, например баллы Grass, в показаниях заработка. Первое показание по каждому источнику даёт начальный баланс. Последующие строки фиксируют прирост, поэтому CSV может начинаться позже самого старого показания в выбранном диапазоне.

Если один и тот же аккаунт читают несколько источников, CSV может посчитать этот доход больше одного раза.

Курс USD берётся из более позднего показания или из записи о выплате. Когда CashPilot задним числом подставляет цену показания, он использует цену CoinGecko на 00:00 UTC этого дня. Для пересчёта USD в выбранную вами валюту CashPilot использует последний справочный курс ЕЦБ на день строки или раньше. Это покрывает выходные, праздники и дни, когда ЕЦБ ещё не опубликовал курс. [Ежедневные курсы Frankfurter](https://frankfurter.dev/v1/)

Frankfurter предлагает для экспорта эти валюты. [Поддерживаемые валюты](https://api.frankfurter.dev/v1/currencies)

- AUD, BRL, CAD, CHF, CNY, CZK, DKK, EUR, GBP, HKD, HUF, IDR, ILS, INR и ISK.
- JPY, KRW, MXN, MYR, NOK, NZD, PHP, PLN, RON, SEK, SGD, THB, TRY, USD и ZAR.

Выберите USD, если вашей валюты нет в этом списке или Frankfurter недоступен.

## Импорт в другой инструмент { #import-into-another-tool }

Перед импортом преобразуйте CSV в формат инструмента. Сначала выберите строки для вашего метода учёта. Пропустите строки выплат для кошелька, который инструмент уже синхронизирует.

### rotki { #rotki }

Используйте Generic Events с этими заголовками.

```csv
Type,Location,Currency,Amount,Fee,Fee Currency,Description,Timestamp
```

Задайте Type равным Income, а Location равным external. rotki также принимает Deposit, Withdrawal, Loss, Spend и Staking, когда эти типы описывают событие. Сопоставьте coin с Currency, amount с Amount и service с Description. Используйте идентификатор актива rotki, когда он отличается от кода coin. Преобразуйте date в метку времени Unix в UTC в миллисекундах. Оставьте оба поля комиссии пустыми. [Generic Events в rotki](https://docs.rotki.com/usage-guides/history/import-data#rotki-generic-events-import)

### Koinly { #koinly }

Используйте обязательные столбцы шаблона Universal.

```csv
Date,Sent Amount,Sent Currency,Received Amount,Received Currency
```

Записывайте Date в формате YYYY-MM-DD HH:mm:ss в UTC. Заполните Received Amount из amount, а Received Currency из coin. Оставьте оба поля Sent пустыми. Для известных значений сопоставьте local_value и local_currency с необязательными Net Worth Amount и Net Worth Currency. Где уместно, используйте столбец Tag со значением mining или reward. Description и TxHash необязательны. [Шаблон Universal в Koinly](https://support.koinly.io/en/articles/9489976-how-to-create-a-custom-csv-file-with-your-data)

Ещё нет аккаунта Koinly? Зарегистрироваться можно здесь: https://koinly.io/?via=FFF185D5. Это реферальная ссылка, и вам она ничего не стоит.

### CoinTracking { #cointracking }

Преобразуйте строки доходов в обычный формат CSV CoinTracking. Custom Importer требует полей сделки с обеих сторон, а у строки дохода есть только сторона покупки. [Требования Custom Importer в CoinTracking](https://cointracking.freshdesk.com/en/support/solutions/articles/29000032507)

```csv
"Type","Buy Amount","Buy Currency","Sell Amount","Sell Currency","Fee","Fee Currency","Exchange","Trade-Group","Comment","Date"
"Income","8","MYST","","","","","","","mysterium","17.11.2025 00:00:00"
```

Задайте Type равным Income или Mining, как уместно. Сопоставьте amount с Buy Amount, coin с Buy Currency и service с Comment. Оставьте поля Sell пустыми. Записывайте Date в формате DD.MM.YYYY HH:MM:SS. Экспорт даёт день в UTC, поэтому в качестве времени используйте 00:00:00. Используйте названия типов на языке вашего аккаунта. [Обычный формат CSV в CoinTracking](https://cointracking.freshdesk.com/en/support/solutions/articles/29000038366-how-can-i-import-2gether-csv-data-into-cointracking-)

Ещё нет аккаунта CoinTracking? По этой ссылке для регистрации вы получаете скидку 10% на любой платный тариф: https://cointracking.info?ref=G962413. Это реферальная ссылка. CoinTracking платит проекту CashPilot 20% от того, что платите вы, и вам это не обходится дороже.
