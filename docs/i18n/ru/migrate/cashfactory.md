# Переход с CashFactory { #moving-from-cashfactory }

CashPilot умеет читать `.env` CashFactory и переносить ваши логины к сервисам, чтобы
вам не пришлось вводить их снова. Вы проверяете всё, прежде чем CashPilot это сохранит.

## Перед началом { #before-you-start }

Вам нужны аккаунт владельца CashPilot и хотя бы один воркер CashPilot.

Остановите CashFactory на машине, прежде чем разворачивать там те же сервисы из
CashPilot. Две копии за одним подключением зарабатывают как одна, а один и тот же id устройства
EarnApp нельзя запускать дважды. Выполните `docker compose down` в папке
CashFactory. Его
[файл compose](https://github.com/OlivierGaland/CashFactory/blob/0ff4bd0c3b020d82c91e095db43ba5c9e356ac94/docker-compose.yml)
также запускает три контейнера, которые монтируют сокет Docker: Portainer (строка 31)
и два контейнера Watchtower (строки 141 и 264). Убедитесь, что и их больше нет: `docker ps` не должен
показывать ни одного из них.

## Какой файл использовать { #which-file-to-use }

Используйте файл `.env` в папке CashFactory, тот, который вы заполнили по
[образцу](https://github.com/OlivierGaland/CashFactory/blob/0ff4bd0c3b020d82c91e095db43ba5c9e356ac94/.env).

Docker Compose читает этот файл и раскрывает `$` в значениях, которые не заключены в
одинарные кавычки. Такое значение — не то, что показывает файл, поэтому CashPilot просит
вас ввести его заново, а не гадает.

## Как импортировать { #how-to-import }

1. Откройте **Settings** (Настройки), затем **Import from another tool** (Импорт из другого инструмента) (или перейдите на `/import`).
2. Добавьте файл `.env` или вставьте его текст. Оставьте для инструмента вариант «Tell from the
   files» («Определить по файлам») или выберите CashFactory.
3. Проверьте таблицу. Отметьте нужные сервисы и заполните все значения, отмеченные как
   отсутствующие.
4. Нажмите **Save the ticked services** (Сохранить отмеченные сервисы), затем разверните их на своих воркерах с
   той же страницы.

## Что переносится { #what-comes-over }

| Приложение CashFactory | Читаемые ключи | Сервис CashPilot | Что переносится |
|---|---|---|---|
| `earnapp` | `EARNAPP_DEVICE_ID` | EarnApp | id устройства, чтобы привязанное устройство продолжало зарабатывать |
| `honeygain` | `HONEYGAIN_EMAIL`, `HONEYGAIN_PASSWD` | Honeygain | email, пароль |
| `iproyalpawns` | `IPROYALPAWNS_EMAIL`, `IPROYALPAWNS_PASSWD` | IPRoyal Pawns | email, пароль |
| `packetstream` | `PACKETSTREAM_CID` | PacketStream | CID |
| `traffmonetizer` | `TRAFFMONETIZER_TOKEN` | Traffmonetizer | токен |
| `repocket` | `RP_EMAIL`, `RP_API_KEY` | Repocket | email, API-ключ |
| `proxylite` | `PROXYLITE_USER_ID` | ProxyLite | id пользователя |
| `proxyrack` | `PROXYRACK_HOST_UUID` | ProxyRack | UUID устройства |
| `earnfm` | `EARNFM_APIKEY` | Earn.fm | API-ключ |
| `peer2profit` | `PEER2PROFIT_EMAIL` | Peer2Profit | ничего: больше недоступен |

Значение, в котором всё ещё стоит заглушка из образца (`<email>`, `sdk-node-<md5sum>`),
считается незаданным, а сервис, у которого нет ничего, кроме заглушек, не показывается в
таблице.

## Что не переносится никогда { #what-never-comes-over }

- **`DEVICE_NAME`.** CashPilot называет каждое устройство по воркеру, на котором оно работает, поэтому
  два воркера никогда не сообщают одно и то же имя. Ваши старые устройства остаются в списке как
  офлайн в панели каждого провайдера, пока вы не удалите их там.
- **Bitping.** CashFactory хранит логин Bitping в томе Docker, а не в
  `.env`, поэтому импорту нечего читать, и строки Bitping нет. Введите
  логин в форме развёртывания Bitping.
- **Portainer и Watchtower.** CashPilot сам управляет своими контейнерами и обновляет их.

## Отслеживание заработка { #earnings-tracking }

Для Honeygain и IPRoyal Pawns логин контейнера совпадает с логином аккаунта,
поэтому CashPilot заполняет и их учётные данные для сбора заработка, если только вы уже не задали
их в настройках. Для всех остальных сервисов добавьте логин для сбора заработка в
**Settings > Earnings collection** (Настройки > Сбор заработка).

## Безопасность { #safety }

- Ничто в файле не выполняется и не раскрывается, и ни один адрес из него не запрашивается.
- Файл читается один раз и не хранится. То, что вы сохраняете, хранится в зашифрованном виде, как
  и все остальные учётные данные в CashPilot.
- Секреты на странице показываются только как «set» («задано»).
- Сохранённые импорты остаются на странице импорта, пока вы не нажмёте **Forget** (Забыть), чтобы вы могли
  позже развернуть их на других воркерах.
