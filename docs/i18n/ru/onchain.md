# Ончейн-балансы выплат { #on-chain-payout-balances }

Откройте **Payouts** (Выплаты), чтобы увидеть баланс на публичном адресе выплат. Bitcoin использует
[mempool.space](https://mempool.space/docs/api/rest), а Kaspa использует
[api.kaspa.org](https://api.kaspa.org/docs). Ethereum, Polygon и Solana используют
публичные RPC-узлы. CashPilot может читать эти адреса без ключа.

| Что вы видите | Что это значит |
|---|---|
| Сумма | Обозреватель сообщил баланс. Нулевой баланс показывается как ноль. Наведите курсор на сумму, чтобы увидеть источник. |
| Ожидание | В Bitcoin обозреватель видит неподтверждённое изменение. Плюс означает, что средства поступают. Минус означает, что средства расходуются. Подтверждённая сумма показывается отдельно. |
| Не удалось проверить | Обозреватель не ответил или прислал данные, которые CashPilot не смог прочитать. |
| Адрес недействителен | Адрес не прошёл проверку формата. CashPilot пропустил запрос. |
| Приватная сеть | Чтобы прочитать баланс Monero, нужен ваш приватный ключ просмотра. Проверьте баланс в своём кошельке. CashPilot никогда не просит у вас этот ключ. |
| Прочерк | Для этой строки нет адреса или средства чтения, или запрос выключен. Когда запрос выключает настройка, наведите курсор на прочерк, чтобы увидеть, какая именно. |

Публичная точка доступа Kaspa сообщает один баланс. Отдельной суммы в ожидании
она не даёт.

Ончейн-столбец показывает баланс на адресе прямо сейчас. Он может включать
переводы из других источников. Невыплаченный баланс пула показывает, что пул
ещё держит для вас. Выплата OCEAN через Lightning не появляется в
ончейн-балансе. Баланс также не может сказать, какие переводы пришли от
вашего пула.

## Выберите, куда идёт запрос { #choose-where-the-lookup-goes }

Каждый запрос сообщает обозревателю ваш публичный адрес выплат и IP сервера UI.
Обозреватель может связать адреса, которые вы проверяете с одного IP.

Если вы запускаете собственный узел, задайте базовый URL в окружении контейнера UI.
Не задавайте переменную, чтобы использовать значение по умолчанию. Задайте ей пустое значение, чтобы выключить
запрос для этой сети.

Например, файл переопределения Compose для сервиса UI может содержать:

```yaml
services:
  cashpilot-ui:
    environment:
      CASHPILOT_ONCHAIN_URL_BITCOIN: "http://mempool.local:3006/api"
      CASHPILOT_ONCHAIN_URL_KASPA: ""
```

Для Bitcoin или Kaspa используйте базовый URL API Esplora или Kaspa.
Точка доступа Bitcoin также даёт сложность сети и награды за блок для
[ожидаемого заработка](fleet.md#running-costs) Bitcoin-пула. Для этого нужен
бэкенд mempool (его API `/v1/mining`); простой сервер Esplora отвечает только на
запрос баланса, и тогда в строке пула не показывается ожидаемая сумма.
Для Ethereum, Polygon и Solana задайте соответствующие переменные
`CASHPILOT_ONCHAIN_URL_ETHEREUM`, `CASHPILOT_ONCHAIN_URL_POLYGON` или
`CASHPILOT_ONCHAIN_URL_SOLANA` равными RPC URL узла. Используйте URL HTTP или HTTPS
без учётных данных, строки запроса и фрагмента. Чтобы применить изменение,
пересоздайте контейнер UI с новым окружением.
