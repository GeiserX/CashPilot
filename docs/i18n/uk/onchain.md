# Ончейн-баланси виплат { #on-chain-payout-balances }

Відкрийте **Payouts** (Виплати), щоб побачити баланс на публічній адресі виплат. Для Bitcoin використовується
[mempool.space](https://mempool.space/docs/api/rest), а для Kaspa —
[api.kaspa.org](https://api.kaspa.org/docs). Ethereum, Polygon і Solana використовують
публічні вузли RPC. CashPilot може читати ці адреси без ключа.

| Що ви бачите | Що це означає |
|---|---|
| Сума | Експлорер повідомив баланс. Повідомлений нуль показується як нуль. Наведіть курсор на суму, щоб побачити джерело. |
| **Pending** (Очікує) | У Bitcoin експлорер бачить непідтверджену зміну. Плюс означає, що кошти надходять. Мінус означає, що кошти витрачаються. Підтверджена сума показується окремо. |
| **Could not check** (Не вдалося перевірити) | Експлорер не відповів або надіслав дані, які CashPilot не зміг прочитати. |
| **Address not valid** (Недійсна адреса) | Адреса не пройшла перевірку формату. CashPilot пропустив запит. |
| **Private chain** (Приватний блокчейн) | Щоб прочитати баланс Monero, потрібен ваш приватний ключ перегляду. Перевірте баланс у своєму гаманці. CashPilot ніколи не просить у вас цей ключ. |
| Прочерк | Для цього рядка немає адреси чи засобу читання, або перевірку вимкнено. Коли перевірку вимикає параметр, наведіть курсор на прочерк, щоб побачити, який саме. |

Публічна кінцева точка Kaspa повідомляє один баланс. Окремої суми, що очікує,
вона не надає.

Ончейн-стовпець показує баланс на адресі прямо зараз. Він може включати
перекази з інших джерел. Невиплачений баланс пулу показує, що пул
досі тримає для вас. Виплата OCEAN через Lightning не з'являється в
ончейн-балансі. Також баланс не може сказати вам, які перекази надійшли від
вашого пулу.

## Виберіть, куди йде перевірка { #choose-where-the-lookup-goes }

Кожна перевірка передає експлореру вашу публічну адресу виплат і IP сервера UI.
Експлорер може пов'язати адреси, які ви перевіряєте з тієї самої IP.

Якщо у вас власний вузол, задайте базовий URL у середовищі контейнера UI.
Не задавайте змінну, щоб використовувати типове значення. Задайте їй порожнє значення, щоб вимкнути
перевірку для цього блокчейну.

Наприклад, перевизначення Compose для сервісу UI може містити:

```yaml
services:
  cashpilot-ui:
    environment:
      CASHPILOT_ONCHAIN_URL_BITCOIN: "http://mempool.local:3006/api"
      CASHPILOT_ONCHAIN_URL_KASPA: ""
```

Під час налаштування Bitcoin або Kaspa використовуйте базовий URL API Esplora або Kaspa.
Кінцева точка Bitcoin також дає складність мережі та винагороди за блок для
[очікуваного заробітку](fleet.md#running-costs) пулу Bitcoin. Для цього потрібен
бекенд mempool (його API `/v1/mining`); звичайний сервер Esplora відповідає лише на
перевірку балансу, і тоді рядок пулу не показує очікуваної суми.
Для Ethereum, Polygon і Solana задайте відповідні змінні
`CASHPILOT_ONCHAIN_URL_ETHEREUM`, `CASHPILOT_ONCHAIN_URL_POLYGON` або
`CASHPILOT_ONCHAIN_URL_SOLANA` як URL RPC вузла. Використовуйте URL HTTP або HTTPS
без облікових даних, рядка запиту чи фрагмента. Застосуйте зміну,
створивши контейнер UI заново з новим середовищем.
