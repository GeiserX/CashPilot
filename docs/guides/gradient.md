## Description

Gradient Network is a decentralized compute and bandwidth sharing platform backed by Pantera Capital. Users earn Gradient Points by running a browser-based node that contributes idle resources to the network. The project focuses on building open AI infrastructure through distributed edge computing. Sentry Node rewards ended on 28 August 2025, and the browser node earns nothing now.
