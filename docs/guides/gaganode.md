> **Category:** DePIN | **Status:** Dead

## Description

GagaNode was a multi-platform decentralized bandwidth sharing network that ran on Windows, Linux, macOS, ARM devices, and Raspberry Pi. The project is gone: its domain is parked and its dashboard, where withdrawals were made, no longer answers.
