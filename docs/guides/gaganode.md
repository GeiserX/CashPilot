## Description

GagaNode is a multi-platform decentralized bandwidth sharing network that runs on Windows, Linux, macOS, ARM devices, and Raspberry Pi. It provides a wide range of platform support making it suitable for headless servers and SBCs. The network monetizes idle bandwidth by routing legitimate traffic through residential and datacenter connections.
