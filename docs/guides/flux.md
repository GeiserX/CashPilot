# Flux

> **Category:** GPU Compute | **Status:** Active
>
> **Website:** [https://runonflux.io](https://runonflux.io)

## Description

Flux is a globally distributed compute infrastructure. Node operators stake FLUX tokens and provide server resources. Three tiers: Cumulus (1,000 FLUX), Nimbus (12,500 FLUX), Stratus (40,000 FLUX). Official Docker images available.

## Setup Instructions

### 1. Create an account

Sign up at [Flux](https://runonflux.io).

### 2. Run it outside CashPilot

CashPilot cannot deploy Flux. The catalog has no Docker image for it, so its row in **Catalog** shows **Visit** instead of **Add**. Run a FluxNode with Flux's own software on a Linux server. CashPilot does not read Flux earnings either, so check them in the provider's dashboard.

## Docker Configuration

None. The catalog has no Docker image for Flux.
