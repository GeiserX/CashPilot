# Nodepay

> **Category:** DePIN | **Status:** Active
>
> **Website:** [https://nodepay.ai](https://nodepay.ai)

## Description

Nodepay is a DePIN network that rewards users for sharing bandwidth through a browser extension. The platform is behind Cloudflare protection which can complicate automated access. Users earn Nodepay Points by keeping the extension active. The network focuses on providing AI training data infrastructure.

### 2. Run it outside CashPilot

CashPilot cannot deploy Nodepay. The catalog has no Docker image for it, so its row in **Catalog** shows **Visit** instead of **Add**. Install the Nodepay browser extension and log in. CashPilot does not read Nodepay earnings either, so check them in the provider's dashboard.
