## Description

DAWN runs a validator network that checks bandwidth and coverage for the AI infrastructure financed through the DAWN protocol. The DAWN Validator browser extension takes part in these proof-of-bandwidth and coverage checks and earns DAWN points while it runs. The points have no cash value yet. Create the account in the extension and enter referral code 2QLQV97F when it asks.

## Setup Instructions

### 1. Install the extension and create an account

Install the [DAWN Validator extension](https://chromewebstore.google.com/detail/dawn-validator-chrome-ext/fpdkjdnhkakefebpekbdhillbhonfjjp) and create your account in it. When it asks **Do you have any referral code?**, enter `2QLQV97F`. The [DAWN website](https://infrastructure.finance/validator-extension?code=2QLQV97F) does not pass the code on, so type it in the extension.

<small>Referral code and link: the CashPilot maintainer may earn a commission from it.</small>

### 2. Run it outside CashPilot

CashPilot cannot deploy Dawn Internet. The catalog has no Docker image for it, so its row in **Catalog** shows **Visit** instead of **Add**. Keep the extension running and logged in. CashPilot does not read Dawn Internet earnings either, so check them in the provider's dashboard.
